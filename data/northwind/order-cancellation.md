# Cancelling an order

A Northwind order may be cancelled within one hour of purchase if it has not been
dispatched. Contact support immediately with your order number. Support must check
the current order status before confirming a cancellation; sending a request alone
does not guarantee that it succeeded.

## After dispatch

A shipped order cannot be cancelled or recalled. Receive the parcel and use the
returns process if the item is eligible. Do not promise a cancellation when tracking
already shows carrier acceptance. Cancellation and refund processing are separate
operations; any proposed mock refund in this demo still requires human approval.

## Changing items

Support cannot add products or change a size after checkout. If the order is still
eligible, request cancellation and place a new order yourself. A cancelled order is
not eligible for a second refund. Card authorization holds follow the payments policy.

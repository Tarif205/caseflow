# Size and color exchanges

Northwind does not process direct exchanges. If an unused item has its original
tags and is within the 30-day return window, start an authorized return and place
a separate order for the desired size or color. The new order uses current prices
and available stock; support cannot reserve stock while waiting for a return.

## Costs and exceptions

A change-of-mind return has the normal 5-dollar return postage deduction. Shipping
for the replacement purchase follows the shipping policy. A sale price from the
original purchase is not automatically transferred. If Northwind sent the wrong
size or color, report it under damaged and incorrect items instead; Northwind then
covers approved return postage.

## Getting the right fit

Check the product's size chart before ordering again. A request for an exchange
does not bypass the return eligibility checks, and a new order is paid separately.
